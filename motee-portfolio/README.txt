VERIFY / REWRITE BEFORE DEPLOYING:
1. Replace CV_Name.pdf with your final CV PDF if the included draft is not the version you want.
2. Add the real GitHub URL for each project; buttons are intentionally disabled until you do.
3. Add screenshots/videos using the exact filenames shown on each project page.
4. Review the research-oriented PFE wording and adjust target geography/availability if needed.
5. Rewrite each "What I learned" section with your own concrete lessons.
6. Add only metrics you can prove. Existing "To measure" tiles are intentionally conservative.

GITHUB PAGES DEPLOYMENT
1. Create a GitHub repository, e.g. motee-portfolio.
2. Upload this folder's contents to the repository root.
3. Put your CV PDF at the root as CV_Name.pdf.
4. Commit and push.
5. GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
6. Wait for the Pages URL to become available.

UPDATING LATER ON GITHUB
- Edit index.html for profile text, projects and links.
- Edit projects/*.html for individual project pages.
- Edit style.css for visual changes.
- Edit site.js for interactions.
- Upload new images to images/ and videos to videos/ using the exact placeholder filenames.
- Commit changes; GitHub Pages redeploys automatically.

NO EXTERNAL REQUESTS
The site uses only HTML/CSS/JS and system fonts. No framework, build step, CDN, API or external font is required.
