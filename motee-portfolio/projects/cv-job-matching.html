Intelligent CV / Job Matching System

An AI platform connecting candidate profiles and job offers through document extraction, LLM reasoning, embeddings and vector similarity search.

Problem

CVs and job offers contain heterogeneous text that must be extracted and structured before candidates and recruiters can search for semantic compatibility.

Solution

The system includes candidate, recruiter and admin modules; CV extraction with PDF/OCR tools; JSON structuring; LLM-assisted reasoning and chat; embeddings; and PostgreSQL + pgvector similarity search.

Architecture

Candidate CVs and job offers enter the system as documents and structured inputs.

Stack

Python · FastAPI · Groq API / LLaMA 3.3 70B · Ollama / nomic-embed-text · pgvector · PostgreSQL · pdfplumber · PyMuPDF · Tesseract OCR · DeepFace
