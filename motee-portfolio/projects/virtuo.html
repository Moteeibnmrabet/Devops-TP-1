Intelligent Financial Analysis Platform

A platform for automatic extraction of accounting data from French CERFA tax documents, financial KPI computation and recommendation generation.

Problem

Financial analysts need to import tax documents, recover structured financial fields, calculate indicators and interpret the resulting data. The project addressed this workflow with an integrated web platform.

Solution

Built a full-stack platform combining PDF processing and OCR, financial KPI computation, a dashboard and rule-based recommendations, exposed through a secured FastAPI REST API and containerized with Docker.

Architecture

PDF documents are imported as the source financial documents, including native and scanned files.

Stack

React.js · FastAPI · Python · PostgreSQL · SQLAlchemy · JWT · Tesseract OCR · pdfplumber / PyPDF · Pandas · Docker · REST API
